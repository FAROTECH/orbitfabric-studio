# OrbitFabric Studio Archive

This directory contains historical planning, release, development and QA material that remains useful as project context but no longer represents the current public-preview baseline.

Archived material is preserved for traceability.

Current-facing documentation should remain in the repository root, `docs/`, `docs/qa/`, or other active documentation locations.

## Sections

- `release-checklists/` — historical root-level release checklist files.
- `releases/` — historical release notes.
- `development/` — historical implementation notes.
- `roadmap/` — historical milestone and roadmap planning documents.

## Policy

Archive before deletion.

Historical documents may be moved here when they are no longer part of the active project contract but still explain earlier decisions, release paths, implementation pivots or QA context.

Deletion requires a dedicated cleanup decision with an explicit file list and rationale.
