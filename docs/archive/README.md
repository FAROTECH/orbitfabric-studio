# OrbitFabric Studio Archive

This directory contains historical planning, release and QA material that remains useful as project context but no longer represents the current public-preview baseline.

Archived material is preserved for traceability.

Current-facing documentation should remain in the repository root, `docs/`, `docs/qa/`, or other active documentation locations.

## Policy

Archive before deletion.

Historical documents may be moved here when they are no longer part of the active project contract but still explain earlier decisions, release paths, or implementation pivots.

Deletion requires a dedicated cleanup decision with an explicit file list and rationale.
