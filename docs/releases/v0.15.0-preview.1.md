# OrbitFabric Studio 0.15.0 Preview 1

**Release:** `v0.15.0-preview.1`  
**Distribution:** developer/source prerelease  
**Validated Core baseline:** `47d37ec2c50eae40e13303eea900eb119bd2e0dd`

OrbitFabric Studio is a local-first engineering workbench for seeing and understanding OrbitFabric missions.

> OrbitFabric Core owns the fact. Studio makes the fact understandable.

## What this preview delivers

Preview 1 provides one complete mission-understanding journey:

```text
Open Mission
  -> Mission Atlas
  -> Explore / Entity X-Ray
  -> Relations / Context Path / Context Map
  -> Validation Findings / exact entity inspection
  -> Operations / Operational State Map / Mode Focus
```

Highlights:

- presence-driven Mission Atlas / Overview;
- transversal Entity Explorer and domain filtering;
- type-aware Entity X-Ray with provenance and immediate relationships;
- global domain-qualified selection and user-followed Context Path;
- Relationship Explorer and explicit Core-owned Context Map;
- complete Core lint findings with stable severity filters;
- exact navigation from a finding to its indexed entity;
- Operations Logic Lens for declared modes, transitions, commands, commandability and recovery contracts;
- ELK-owned orthogonal routing rendered through React Flow;
- progressive mission hydration and transactional refresh;
- release-ready desktop and launcher identity.

## Trust boundary

Studio does not replace OrbitFabric Core.

It consumes structured Core-owned Mission Snapshot, Entity Index, Relationship Manifest and lint surfaces. It does not semantically parse Mission Model YAML, infer missing relationships, invent mission behavior or calculate private health/readiness/completeness scores.

Mission Model source remains read-only.

## Run from source

This prerelease intentionally does not include binary installers.

Follow the complete prerequisites, pinned Core installation, verification and launch instructions in the [README](../../README.md).

On hosts affected by the WebKitGTK DMA-BUF rendering issue, use:

```bash
WEBKIT_DISABLE_DMABUF_RENDERER=1 npm run tauri:dev
```

## Known limitations

- Developer/source distribution only.
- Binary packaging and Core sidecar strategy are deferred.
- Signing and notarization are deferred.
- The production frontend bundle is functional but still large; optimization is tracked in [#255](https://github.com/FAROTECH/orbitfabric-studio/issues/255).
- Debian 12 is the primary clean-clone and real-desktop acceptance host; Windows 11 has additional source-build and real-desktop acceptance. macOS and other platforms remain outside the Preview 1 acceptance claim.
